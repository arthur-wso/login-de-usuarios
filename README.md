# Login de Usuários

Sistema web de **autenticação e gerenciamento de usuários**, desenvolvido com o objetivo de aplicar na prática conceitos de desenvolvimento **Front-end e Back-end**, integração entre aplicações e organização de projetos.

O projeto está dividido em duas partes principais: uma aplicação responsável pela interface do usuário e outra responsável pela lógica do sistema e gerenciamento das informações.

---

## Sobre o projeto

O **Login de Usuários** é um projeto desenvolvido para estudar e aplicar conceitos fundamentais de desenvolvimento web, com foco na criação de um sistema de autenticação.

A aplicação permite estruturar um fluxo de usuários desde a interface de login até o processamento das informações no Back-end.

Além de servir como projeto de estudo, este repositório faz parte do meu processo de aprendizado e evolução como desenvolvedor.

---

## Funcionalidades
